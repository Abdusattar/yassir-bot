# Монтажёр «Яссир Медиа»

## Спецификация — `media/style.md`
Всё про кадр, движение, переходы, темп, звук и выход задано числом в `media/style.md` (уровень 6).
Перед сборкой прочитай его целиком; при расхождении со скиллом прав `style.md`. Здесь — только
инструменты и ключевые числа для памяти.

## Как собирается ролик (style §4, §5, §12)
- Вход — монтажный лист `videos/NN_имя/sheet.json` (style §5); руками кадры не правим, правим лист.
- Одна HTML-страница, `render(t)` — все свойства чистые функции `t`; CSS-transition/animation
  выключены; `will-change` не ставить. Playwright снимает кадр за кадром (30 к/с) в `frames/`.
- ffmpeg только режет живые клипы в PNG и собирает PNG + звук. **`zoompan` и `xfade` не использовать**
  (дрожь и ручная склейка — проблемы всех трёх черновиков).

## Инструменты (уже в репо)
- Кадры с аятом: `media/tools/teaser01_render.py`, `video01_v2_render.py`, `video02_render.py`,
  `video03_render.py`, `video04_render.py` — старые сборщики черновиков; генератор строится по style §13.
- Глифы мусхафа: `mushaf_data/pageN.json` (ayahs[].tokens[]: code_v4, html — в нём знаки вакфа,
  translation — пословно; `type: ayah_end` — знак аята). **Шрифт только V2**
  `https://static-cdn.tarteel.ai/qul/fonts/quran_fonts/v2/woff2/pN.woff2`, аят монохромный (V4 не берём).
- Чтение: Аль-Афаси `https://download.quranicaudio.com/qdc/mishari_al_afasy/murattal/{сура}.mp3`,
  тайм-коды слов `https://api.qurancdn.com/api/qdc/audio/reciters/7/audio_files?chapter=N&segments=true`.
- Экраны приложения: `media/tools/video03_screens.py` (стенд). **Перед съёмкой прочитать, что
  за аяты на странице** — не снимать страницы с аятами о лицемерах/наказании для «Пути».
- Живые кадры: Pexels (бесплатно, без указания автора), проверять кадрами, что чувство совпадает;
  синий кадр греть по style §1.

## Ключевые числа (полностью — style.md)
- Палитра светлая «страница мусхафа» (style §1): бумага `#f7efdf → #fbf6ea → #f3e8d3` + свет
  `#fffaf0`; арабский `#1d1a16`, не прозвучавшие `rgba(29,26,22,.25)`, звучащее `#2f6fe4`, ключевое
  `#b07a1e`; мельче 88 px — `#2456b8` / `#8a6015`; служебные Inter `#6f6557`. Теней нет, аят только
  на бумаге, живой кадр — текст на светлой карточке. Финал — синий знак-книга (аватар) + YASSIR.
- Поле 1080×1920: верх ≥270, низ до y 1250, бока ≥65; ниже y 1050 — ширина ≤820 (иконки Reels).
- Сетка: режимы A / B / C (style §3); аят 118 px, ступени по 6% до 88; одна раскладка на ролик,
  балансный перенос ≤25%, перенос по вакфу (style §2).
- Значения ≥46 px Cormorant или Inter 40; источник Inter 40; перевод 60 px, ширина ≤820.
- Наезд 1,00→1,04 на **план** (не на сцену); переезд аята 0,5 с; растворение 0,35 с; смена
  подписи 0,25 с; слово загорается за 0,1 с.
- Перевод — с последним словом аята, не раньше голоса; ≥4 с при 10+ словах. Смена текста — на
  границе слова ±100 мс или в паузе ≥300 мс. После чтения ≤1,5 с без нового элемента; знак 1,5 с.
- Звук: 48 кГц, `loudnorm I=-16:TP=-1.5:LRA=11` в два прохода, фейды 30–50 мс, проверка хвостов,
  `apad` + `-t`; синхрон слова ±60 мс, подсветка опережает на 40 мс; начало слова — RMS > −40 dBFS.
- Выход: H.264 High CRF 18, yuv420p, bt709 ×3, CFR 30, `+faststart`, AAC 192k 48 кГц (команда — style §12).
  Без музыки и ИИ-звука. Аят ≥40% времени.

## Проверка перед показом (обязательно)
1. Чек-лист style §11 целиком (сам, затем агент `media-craft`).
2. `ffprobe`: длительность звука и видео ±1 кадр, теги по §12; `silencedetect` — −∞ не дольше 2 с.
3. Ключевые кадры в полосу (`ffmpeg -ss t … hstack`) — посмотреть глазами каждый.
4. README ролика: файлы (имена по style §12), тайминг, источники, что осталось. Тяжёлые файлы в git не идут.
