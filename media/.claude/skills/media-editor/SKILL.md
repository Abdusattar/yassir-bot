# Монтажёр «Яссир Медиа»

## Инструменты (уже в репо)
- Кадры с аятом: `media/tools/teaser01_render.py` (HEAD, стиль), примеры: `video01_v2_render.py`,
  `video02_render.py`, `video03_render.py`. PNG 1080×1920, Playwright Chromium.
- Глифы мусхафа: `mushaf_data/pageN.json` (ayahs[].tokens[].code_v4, translation — пословно).
  **Шрифт:** V2 `https://static-cdn.tarteel.ai/qul/fonts/quran_fonts/v2/woff2/pN.woff2` (коды те же).
  V4-таджвид `.../v4-tajweed/woff2/pN.woff2` даёт цвета, НО у некоторых глифов дефект (кясра в
  рамке у فِيهِ, стр. 2) — после рендера V4 смотреть кадр крупно; сомнение → V2.
- Чтение: Аль-Афаси `https://download.quranicaudio.com/qdc/mishari_al_afasy/murattal/{сура}.mp3`,
  тайм-коды слов `https://api.qurancdn.com/api/qdc/audio/reciters/7/audio_files?chapter=N&segments=true`.
  Вырезать `ffmpeg -ss … -t … -i URL`, края проверять по RMS (хвост прошлого аята / начало
  следующего), фейды 30 мс.
- Экраны приложения: `media/tools/video03_screens.py` (стенд). **Перед съёмкой прочитать, что
  за аяты на странице** — не снимать страницы с аятами о лицемерах/наказании для «Пути».
- Живые кадры: Pexels (бесплатно, без указания автора), проверять кадрами, что чувство совпадает.

## Стандарт кадра
Текст в безопасных зонах 1080×1920: сверху ≥270, снизу ≥670, бока ≥65 px. Без музыки.
Звук только чтение + живые шумы (ИИ-звук → пометка или замена). Аят ≥40% времени.

## Против «слайд-шоу»
Всегда движение: медленный наезд на весь ролик
(`scale=2160:3840,zoompan=z='1+0.00009*on':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=1080x1920:fps=30`),
живые кадры, слова загораются по тайм-кодам. Тишина — акцент ≤2 с, не заполнитель;
после чтения держать ≤1,5 с, знак ≤1,5 с.

## Проверка перед показом (обязательно)
1. Длительность `ffprobe`; `silencedetect` — нет ли провалов > 2 с там, где не задумано.
2. Ключевые кадры в полосу (`ffmpeg -ss t … hstack`) — посмотреть глазами каждый.
3. Громкость `loudnorm I=-16:TP=-1.5`.
4. README ролика: файлы, тайминг, источники, что осталось. Тяжёлые файлы в git не идут.
