# Ролик 2 — «Ты учишь — а понимаешь?»

**Статус:** черновик собран 05.10.2026 (`draft_v1.mp4`, 27,8 с), ждёт просмотра на
телефоне. Рубрика — для своих (ученики и семьи), знак серии единый.

## Шаг 1. Бриф (согласован 05.10)

- **Для кого:** свои (~195 учеников) и их семьи — уже учат Коран наизусть.
- **Мысль:** выучить звук — начало; понять слово — услышать, что Аллах говорит тебе.
- **Чувство:** тёплое «я это знаю наизусть — а не понимал»; без укора.
- **После:** пересылает, сохраняет; свои открывают тренажёр «Слова» (призыва в ролике нет).
- **Аят 2:2** «ذَٰلِكَ ٱلْكِتَٰبُ لَا رَيْبَ ۛ فِيهِ ۛ هُدًى لِّلْمُتَّقِينَ» — стр. 2, её знает
  каждый, даже подготовительная; Коран сам называет себя «руководством».
- **Источники (сверено 05.10):** глифы V4 — `mushaf_data/page2.json`; пословно — та же
  база, что в тренажёре (`mufradat_words`, Quran Academy): Это · Писание · нет ·
  сомнения · в нём · руководство · для остерегающихся; Кулиев (quran.com): «Это
  Писание, в котором нет сомнения, является верным руководством для богобоязненных,»
  — в кадре запятая конца заменена на «…» (предложение продолжается в 2:3).
- **Чтение:** Аль-Афаси, qdc reciter 7, `murattal/2.mp3`, отрезок 7,60–16,60 с (края
  проверены по громкости: до 7,60 — хвост «الم», после 16,60 — начало 2:3). Слова
  (от начала отрезка): 0 / 0,895 / 1,795 / 2,175 / 2,745 / 5,005 / 5,305.
