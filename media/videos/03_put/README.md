# Ролик 3 — «Путь» (приложение как инструмент)

**Статус:** черновик собран 05.10.2026 (`draft_v1.mp4`, 27,3 с), ждёт просмотра на телефоне.
Третий закреплённый ролик страницы: 1 — зачем Коран, 2 — как понимать, 3 — чем учиться.

## Бриф

- **Для кого:** тронутый роликами 1–2 и спрашивающий «а где этому учиться?»; свои узнают своё.
- **Мысль:** Аллах облегчил Коран — и вот как этот путь выглядит каждый день.
- **Чувство:** «это реально и это для меня». **После:** ссылка в профиле.
- **Аят 54:17** «وَلَقَدْ يَسَّرْنَا ٱلْقُرْءَانَ لِلذِّكْرِ فَهَلْ مِن مُّدَّكِرٍ» — يَسَّرْنَا того же
  корня, что Yassir; вторая половина — приглашение самого Корана. Кулиев (quran.com,
  сверено 05.10): «Мы облегчили Коран для поминания. Но есть ли среди вас вспоминающие?»
  Лист 529, глифы V4 (`mushaf_data/page529.json`). Чтение — Аль-Афаси `murattal/54.mp3`,
  151,92–160,65 с (края проверены по громкости).
- Приложение — инструмент, не герой: настоящие экраны, без обещаний.
