(честнее, узнаваемо, «людей не генерируем»); Flow — только рассвет.

Разбор профи до производства: первая секунда не пустая; суета 4 с, аят ~12 с;
конец тёмный → снова шум начала — ролик пересматривается по кругу; текст в
