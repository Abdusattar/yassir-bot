# Яссир Медиа

Отдельное направление проекта: короткие вертикальные ролики о Коране (Reels,
WhatsApp, Telegram, Shorts). Цель — любовь к Корану и обращение к нему как к
руководству; Яссир — лишь дверь. Фундамент — довольство Всевышнего, без
самолюбования.

**Слово-вход:** пользователь пишет «медиа» → Claude читает этот файл, затем
`mission.md`, `strategy.md`, `process.md`, `journal.md`, и продолжает с «Где остановились».
**Мандат (05.10):** Claude ведёт сам — стратегия, жанры, сценарии, исследования, тафсиры,
рецензия, черновики, разбор цифр. Пользователь решает: публикацию (одно «да» на пачку),
деньги, людей (голоса, съёмки, согласие учеников), закон (удостоверение по закону КР —
взял на себя 05.10), тонкие темы → Умар устаз.
