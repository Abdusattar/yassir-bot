# Яссир Медиа

Отдельное направление проекта: короткие вертикальные ролики о Коране (Reels,
WhatsApp, Telegram, Shorts). Цель — любовь к Корану и обращение к нему как к
руководству; Яссир — лишь дверь. Фундамент — довольство Всевышнего, без
самолюбования.

**Слово-вход:** пользователь пишет «медиа» → Claude читает этот файл, затем
`strategy.md` и `journal.md`, и продолжает с «Где остановились».
