## 02.10.2026 — старт направления

- Пользователь — новичок в видео; его мысли — подсказки, не рамки. Строим по уровню
  профессионалов индустрии.
- **Фундамент:** каждый ролик оцениваем прежде всего с точки зрения довольства
  Всевышнего; без самолюбования («пусть Аллах нас удержит от этого»).
- **Стиль:** в ногу со временем по форме, но благоговение, не хайп. Без музыки, аят
  в центре, перевод только проверенный, Коран — только нашим шрифтом мусхафа.
- **Центральная мысль:** Коран сам отвечает на повседневные вопросы человека.
  Материал широк: сердце, психология, жизнь, сам человек, мироздание.
- **Исследование** (источники в логе сессии): ниша русскоязычных роликов «Коран
  слово за словом» свободна; ближе всего по духу — Нуман Али Хан (одно слово);
  первые 3 секунды решают; ИИ не умеет арабский текст — только фоны; безопасные
  зоны Reels; формула промпта Veo: камера + объект + действие + окружение + стиль.
- **Чтение:** Мишари Аль-Афаси (quranicaudio) — решение пользователя: чтецы
  выкладывают ради награды и для блага, право дано.
- **Ссылки в тизере нет:** «скоро» значит раскрываем постепенно; когда давать
  ссылку — решаем отдельно.
- **Инструменты:** Google Flow (Veo 3.1 Fast) — фоны; Playwright + шрифт V4 — кадры
  с аятом и подсветка слов по тайм-кодам; ffmpeg — сборка.
- **Ролик 1 «Сколько голосов»** собран за день на бесплатных бонусах.
- **Урок:** ролик сделан ДО разбора профессионала — всё найденное было видно ещё в
  сценарии. Теперь порядок с проверками: бриф → сценарий → разбор профи → черновик →
  производство (strategy.md §6).
- Стратегия пересобрана целиком: аудитории ещё нет → каждый ролик цельный; первые
  зрители — свои ~195 учеников; один ролик — четыре двери; 4 рубрики; ритм 3 в неделю.
- Направление вынесено в папку `media/`, слово-вход «медиа».

## 05.10.2026 — разбор «что работает»: @zamzam.premium

Канал туроператора хаджа/умры, 203 тыс. Расшифрованы два хита (yt-dlp + whisper):
- «Трофеи или приказ» (Ухуд, ИИ-кино, 2 мин) — **4,8 млн**; «Могилы» (1 мин) — **1,1 млн**;
  их же лекции «говорящих голов» — 19–98 тыс. Разница в 50–250 раз.
- Формула обоих хитов: крючок-вопрос «Видишь этот/эти…?» → диалог двоих (спрашивает —
  объясняет) → конкретное место и деталь → опора (приказ Пророка ﷺ / аят 3:185) →
  поворот на зрителя («холм у каждого свой», «завтра начну… а его завтра настало здесь»)
  → добивающая фраза.
- Название форматов: у них — диалоговый сторителлинг / ИИ-кинопритча; у нас — Quran edit
  с кинетической типографикой (караоке-подсветка), faceless — сильнее на «сохранить»,
  слабее на «залипнуть» (нет истории).
- Через фильтр: **механику берём** (знание о внимании, не чужое); **ИИ-людей и сцены со
  сподвижниками не берём** (спорно, правило «людей не генерируем»). Кандидат в рубрику
  «Диалог»: два живых голоса за кадром + место/природа + аят нашим шрифтом.
- Пользователь: сценарии должны проходить профессиональную рецензию (не «ты сделал — я
  согласился»), решения — на том, что доказанно работает. → независимый критик в
  process.md, дискуссия показывается пользователю.
