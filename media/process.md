# Конвейер ролика — как работают профи (с 05.10.2026)

Режим, на который перешли по решению пользователя: знания индустрии + дешёвые
инструменты, без курсов и людей со стороны. Идеи со стороны — материал через фильтр
системы (память `feedback_strategy_owner_filter_ideas`), решение — за Claude.

**Креативный директор «третья сторона»** (агент `media-director`) — ревизия всей системы с
чистого листа (жанр, стратегия, план, сценарии, наши правила-гипотезы): при смене стратегии,
перед запуском пачки и раз в неделю с разбором цифр. Шариат не решает — помечает «Умар устаз».

Умар устаза зовём только если тафсиры расходятся или тема тонкая (хадис, сира, фикх).
Пакетами: 3 ролика за заход, пользователь смотрит все разом.

## Шаблон брифа

- **Рубрика:** Коран отвечает / Одно слово / Знамения / Путь
- **Для кого:** незнакомый из ленты / свои — и что он знает о Коране
- **Одна мысль** (одно предложение)
- **Одно чувство**
- **Что делает после** (сохранить / переслать / ссылка в профиле) — без призыва в ролике
- **Аят:** арабский, перевод Кулиева, источник, вывод по тафсиру
- **Крючок первой секунды** (текст + картинка + звук с кадра 0)

## Рубрика критика (каждый пункт: ✓ / ✗ + почему + как исправить)

1. **Первая секунда:** остановит ли палец незнакомца? Есть ли вопрос/напряжение с кадра 0?
2. **Одна мысль:** понятна без подписи, за один просмотр?
3. **Аят в центре:** аяту ≥ 40% времени и воздух; не фон для красивой картинки.
4. **Контекст:** вопрос ролика честно ведёт к смыслу аята по тафсиру, не натянут?
5. **Адаб:** без музыки поверх чтения; нет унижающего рядом с аятом; людей не генерируем.
6. **Без самолюбования:** говорит Коран, не мы; Yassir — тихий знак в конце.
7. **Честность:** нет кликбейта и обещаний; ИИ-кадры помечены.
8. **Удержание:** где зритель уйдёт? провисания > 3 с без нового?
9. **Пересылаемость:** захочется ли отправить другу — что именно он «передаёт»?
10. **Безопасные зоны** 1080×1920: текст в 270 / 670 / 65 px.
11. **Род и обращение:** текст подходит и братьям, и сёстрам (или есть две версии).

Вердикт критика: «выпускать / доработать (что) / не выпускать (почему)».

## Модели (решение пользователя 05.10.2026)
Основная работа (сценарии, сборка, документы) — на основной модели сессии (Opus). **Независимые
рецензенты — `media-director`, `media-critic`, `media-craft` — запускать с моделью Fable** (Agent
`model: "fable"`): самая сильная модель на оценке и «другие глаза», чем у автора. Сессию целиком на
Fable не переключать — дороже и быстро расходует лимит подписки.
