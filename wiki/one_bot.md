# Один бот: @YassirAppBot (с 01.10.2026)

**Направление (решение пользователя 01.10.2026).** Постепенно всё переходит
на @YassirAppBot: сначала личка студентов (этап 1), потом группы (этап 2),
потом боты половин выключаются (этап 3). Требование: «никто не должен
заметить, ничего не ломается»; удобство сразу получают новички.

**Что объединяем, а что нет.** Единым становится голос: бот, чат, имя.
Данные половин остаются раздельными: две базы, два процесса, мужской в
женскую базу не пишет (принцип 18.09). YassirApp — маршрутизатор:
событие уходит той половине, которой оно принадлежит.

## Правило канала

У человека ОДИН канал личных сообщений:
- нажал «Старт» у YassirApp (и режим его включает) → всё личное только
  через YassirApp, бот половины в его личке замолкает;
- иначе — как раньше, бот половины (`users.dm_ok`);
- YassirApp заблокирован → аварийно снова бот половины.

Ответ на сообщение/нажатие в личке бота половины уходит туда же, где
спросили (`app_route.answering_in` / `in_chat` в `bot.py`).

Устазы и суперадмины на этапе 1 — всегда через ботов половин.

## Как устроено (этап 1, шаг 1)

- `core/app_route.py` — таблица `app_dm` в общей `sources/hadiths.db`
  (`started_at`, `newcomer`, `blocked_at`), правило `via_app(chat_id)`.
- `newcomer` решается ОДИН раз, при первой встрече с YassirApp:
  нигде не учился (`app_bot.studies_in` is None). Ставит отметку
  `app_bot.note_contact` на любое сообщение/нажатие в личке YassirApp.
- `core/tg.py` — `_routed`: методы отправки/правки в личный чат идут токеном
  YassirApp, если `via_app`. Явный отказ → тот же запрос своим ботом;
  отказ «заблокировал/не начинал» ещё и ставит `blocked_at`. Сеть молчит
  (None) — не повторяем, чтобы не было дублей.
- `get_dm_ok` / `get_dm_ok_by_phone` считают и канал YassirApp — все места
  «личка открыта? иначе в группу» работают без правок.
- Токен для отправки — `APP_SEND_TOKEN` (тот же `TELEGRAM_TOKEN_APP`) в обоих
  процессах; слушатель (`APP_BOT_TOKEN`) — только мужской. Нет токена в
  `.env` процесса → его студенты как раньше.

## Выключатель `DM_VIA_APP`

| Режим | Кому через YassirApp |
|---|---|
| `off` (по умолчанию) | никому |
| `test` | только `DM_VIA_APP_TEST_IDS` |
| `new` | тестовым + новичкам |
| `all` | всем, кто нажал Старт у YassirApp (этап 2) |

Откат любого круга — вернуть `off`, код не трогать.
