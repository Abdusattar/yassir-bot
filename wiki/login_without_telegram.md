# Вход и учёба без Telegram (разбор 07.10.2026)

**Повод.** Telegram в ряде стран берёт разовую плату за регистрацию нового
аккаунта (SMS-сбор, ~1 $, включает неделю Premium; официального списка стран
нет, зависит от региона, номера, оператора). Для новичка это барьер: карта,
оплата. Вопрос пользователя: сможем ли впускать людей через Google / Apple /
другое, минуя Telegram, и что при этом не сломать.

Источники о сборе: socialecho.net «telegram-registration-fee-2026»,
quarkip.com «Telegram SMS Fee», privacyguides «Telegram Activation Fee».
Страны Telegram не публикует — проверить на кыргызском номере нужно живым
телефоном.

## На чём сегодня держится Telegram

| Что | Как сейчас | Без Telegram |
|---|---|---|
| Личность | `users.phone` = Telegram ID, по нему всё: сессии, след, мусхаф, API (`with_auth` → `user_id`) | нужен свой идентификатор того же вида |
| Регистрация | только вход в группу по ссылке → бот видит join; «брат/сестра» у @YassirAppBot; «Старт» для лички | нужен экран регистрации в приложении |
| Подготовительная | группа в Telegram, 14 дней / 5 полных дней, выпуск = ссылка на группу | «виртуальное» членство без чата |

**Прецедент уже есть:** студенты без Telegram ID (`/add Имя`, N-2a, 23.08) —
бот их считает, не пишет им и не кикает. То есть «студент без Telegram» для
учёта не новость, новое только вход и связь.

## Как сделать, не ломая

1. **Идентификатор.** Таблица `identities(provider, subject, user_id)`:
   `telegram:<id>`, `google:<sub>`, `email:<адрес>`. Человеку без Telegram в
   `users.phone` кладём синтетический id вида `app:<n>` — тогда весь код
   приложения (`find_user_by_phone`, `is_app_member`, след, мусхаф) работает
   без правок.
2. **Связь.** В `core/tg.py` одна развилка: адресат `app:*` → не Telegram, а
   таблица входящих в приложении (экран «Сообщения» + значок на двери;
   веб-пуш на Android, на iOS почти нет — e-mail-дайджест как запас).
   `ban_member`/`unban_member`/`get_chat_member` для `app:*` — no-op. Это
   продолжение правила «один канал на человека» (wiki/one_bot.md):
   каналов становится три — бот половины, YassirApp, входящие.
3. **Вход.** Google Sign-In (бесплатно, OAuth-клиент в Google Cloud, проверка
   id_token на сервере) + e-mail с одноразовым кодом (универсально, без SMS;
   нужен SMTP). Apple — только при спросе: платный аккаунт разработчика
   (99 $/год), для сайта не обязателен. Сессии — те же `web_sessions`.
4. **Регистрация в приложении.** Имя, брат/сестра (решает базу половины, как
   у @YassirAppBot), согласие → `users` + `user_groups` подготовительной
   без чата. Выпуск из prep: вместо ссылки — перенос в relaxed-группу в
   базе; `announce_prep_graduate_arrival` ждёт join — для `app:*` не ждать.
5. **Связывание потом** (чтобы «не было портаков»): в настройках «Привязать
   Telegram» → тот же код входа → бот подтверждает → строка в `identities`,
   `users.phone` меняется на Telegram ID, `users.id` и история целы. Обратно:
   у студента с Telegram добавить Google/e-mail — просто строка в
   `identities`. Дубли («зарегистрировался в приложении, уже учась в
   группе») — экран «уже учишься? тогда войди через Telegram», и инструмент
   слияния у супер-админа.
6. **Онлайн-урок** — если он в видеочате группы Telegram, студент без
   Telegram на него не попадёт. Нужна ссылка на урок (Meet/Zoom) в
   приложении или решение, что такие студенты без урока.

## Что не ломается

- Сдачи: записи и повторение уходят в группу от бота под именем студента —
  как сейчас, его аккаунт не нужен.
- Проверка устаза, вердикты, пересдача, тренажёры, рейтинг, серия, отчёты —
  всё в приложении и в базе.
- Лента группы читается в приложении.
- Существующие студенты не затронуты: Telegram-вход остаётся, второй способ
  входа — добавка.

## Порядок и объём (оценка)

1. Google + e-mail-код как **второй вход для тех, кто уже учится** (связь
   через `identities`) — ~1 день, риск низкий. Даёт страховку тем, кто
   потерял аккаунт.
2. Регистрация без Telegram + канал «входящие» + виртуальная подготовительная
   — ~3 дня, тесты на переводы/выпуск/кик с `app:*`.
3. Ссылка на урок, привязка Telegram позже, слияние дублей — ~1 день.

Правило 22.09 «Telegram — это связь, боту можно написать первым ушедшему»
для таких людей не работает: вернуть их сможет только e-mail/пуш. Это цена,
её надо принять осознанно.
