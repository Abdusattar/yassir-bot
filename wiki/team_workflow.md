# Как мы работаем вместе (предложение, 05.11.2026)

Для Абдусаттара, Эрлана и всех Claude/Fable, которые работают с
репозиторием. Это **предложение**: после обсуждения в группе фиксируем, что
приняли, и переносим в `CLAUDE.md`. Эрлан, прогони, пожалуйста, через Fable:
что лишнее, что упущено, что неудобно в твоём рабочем процессе.

Связанный разбор: `wiki/architecture_roadmap.md` (архитектура и уход от
Telegram).

## Как устроена работа

**Советуемся вместе → решаем вместе → каждый делает свою часть.** У
каждого свой Claude/Fable, и каждый ведёт свои куски проекта.

- **Решения** — общие: что делаем, зачем, в каком порядке, на каком стеке.
  Обсуждаем в группе, договариваемся, записываем в wiki.
- **Части работы** — у каждого свои. Сейчас, например, Эрлан — нижняя
  панель, «Знания», видео; Абдусаттар — заучивание, кабинет устаза, боты.
  Делёж меняется по договорённости.
- **Опыт** — у каждого свой: у Эрлана большой опыт веб-проектов, поэтому
  его взгляд особенно важен в вопросах фронтенда и стека; Абдусаттар
  глубоко знает методику, студентов и устазов.
- **Claude/Fable** — помощники каждого: пишут код, тесты, wiki, следят за
  тем, чтобы правила команды соблюдались.

Обязательное ревью человеком не вводим: оно застопорит работу. Замена —
зелёные тесты + ИИ-ревью PR (Claude или Fable) + снимок экрана для UI.

## Что сегодня мешает — с обеих сторон

Честно, без поиска виноватых:

- **С нашей стороны:** десятки коммитов прямо в `master` без PR; в рабочей
  копии лежат незакоммиченные правки другой сессии; правило перехода 40+40
  живёт уже в трёх копиях (третью добавил Claude 05.11).
- **Со стороны Эрлана:** PR сливаются самим автором за 1–2 минуты, без
  ревью; файл `index.html` однажды загружен целиком через сайт GitHub (при
  несвежей копии так молча откатываются чужие правки); слитые ветки не
  удаляются.
- **Общее:** `mushaf_data/index.html` (18 тыс. строк) — 60 из 187 коммитов за
  месяц. Пока это один файл, мы неизбежно в нём встречаемся.

## Правила (предложение)

1. **Перед работой — `git pull`. Правки — через git** (GitHub Desktop или
   VS Code), а не загрузкой файла через сайт. Тогда git сам покажет
   конфликт, а не затрёт чужое.
2. **Перед большой правкой `index.html` — одно сообщение в WhatsApp:**
   «сегодня трогаю X». Мелочь — без предупреждения.
3. **Всё через PR, и у Абдусаттара тоже** — по мере возможности. PR =
   короткое «что и зачем» + снимок, если менялся экран.
4. **Перед слиянием PR:** зелёные тесты (нужно включить проверку на PR,
   см. ниже) + ИИ-ревью. Сливать можно самому.
5. **Кто выкатил — тот проверяет прод.** Слияние в `master` = выкатка на
   yassirilm.com. После неё: Actions зелёный и сайт реально обновился.
6. **Ветку после слияния удаляем** (в настройках GitHub — галочка
   «Automatically delete head branches»).
7. **UI — снимок 390×844 глазами до слияния**; арабское и RTL — только по
   скриншоту; iPhone от iOS 16.2.

## Общая память для ИИ — важное

Память Claude у Абдусаттара (~130 записей) **локальная**: она лежит на его
компьютере, и Fable Эрлана её не видит. А там много правил, которые важны
всем. Значит, общие правила должны жить **в репозитории**: в `CLAUDE.md`
(его читает любой Claude/Fable, открывший проект) и в `wiki/`.

Ниже — готовый блок для `CLAUDE.md`. Вставим после согласия команды.

> **Никогда не переносим в репозиторий** токены, ключи, адрес сервера,
> SSH: репозиторий публичный.

### Общие файлы — чтобы не конфликтовать

`CLAUDE.md` просит каждого Claude вести `logs/terminal/ДАТА.md` и
`context/summary.md`. Если сессии Абдусаттара и Эрлана пишут в один файл в
один день — конфликт. Предложение: лог с автором в имени
(`logs/terminal/2026-11-05_erlan.md`), а в `context/summary.md` — свои
разделы.

### Готовый блок для `CLAUDE.md` (после «да» команды)

```markdown
## Команда и порядок работы

- Абдусаттар и Эрлан советуются и решают вместе, потом каждый ведёт свою
  часть со своим Claude/Fable. Объяснять решения без жаргона: «что даёт /
  чем рискуем».
- Перед работой `git pull`; правки только через git, не загрузкой через сайт.
- Большая правка `mushaf_data/index.html` — сначала сообщение в группу.
- PR: «что и зачем» + снимок 390×844 для UI; зелёные тесты + ИИ-ревью; ветку удалить.
- Кто выкатил — проверяет прод (Actions + yassirilm.com).
- Свой лог: `logs/terminal/ДАТА_имя.md`.
- Сначала русский; ky/uz/zh потом одним проходом (`T()` откатывается на ru).
- Правило 40+40 (строки, половины, переход, склейка стр. 1–2) — сейчас в трёх
  копиях: `index.html`, `core/mushaf_words.py`, `scripts/generate_hifz_audio.py`.
  Меняешь одну — меняй все, пока не сведены в одну.
```

- Галочка автоудаления веток в настройках репозитория.
- Закрыть или слить PR #1 (открыт с июля).
