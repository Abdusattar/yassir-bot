# 2026-09-18

## Две половины не смешиваются (после случая Динары 17.09)
- Задача пользователя: убрать все места, где человек может попасть в чужой джамаат. «Начать» никого не регистрирует; подтверждённым считается только тот, кто прошёл подготовительную (устаз слышит голос). Новичка ни в одной базе бот отличить не может — это остаётся за устазом подготовительной, лучшего механизма нет.
- Единый принцип: прежде чем завести человека у себя, бот спрашивает соседа (`other_bot_member`), чужого не пишет, показывает дорогу в его бот.
- Настоящая дыра Динары — не строка в базе, а кнопка меню: она одна на всех, а приложение внутри Telegram членство не проверяло вовсе.
- Решения пользователя: (1) сайт — одна кнопка «Войти через Telegram» через мужской бот, тот ищет по обеим базам; виджет Telegram Login отвергнут (просит номер, привязан к одному боту, всё равно две базы); (2) в приложении из чужого бота — экран с кнопкой «Открыть мой YassirApp», не автопереход; (3) чужому в группе — личка и супер-админы, группу не засорять; (4) строка «если ты сестра — тебе сюда» незнакомцу убрана как лишняя; (5) при входе с сайта сестре НЕ говорим, где её бот — приложение уже открылось.
- Сделано: `core/bots.py` (боты представляются друг другу через `bot_registry` в общей hadiths.db, ничего в .env), коды входа переехали в общую базу с колонкой `profile` (сессии остались по базам), `/auth/poll` отвечает `profile` и вкладка переспрашивает нужный процесс, `with_auth` для initData отвечает 403 `wrong_bot`, личка/группа/вход в группу — `redirect_to_other_bot`, `handle_other_bot_member_in_group`. Плашка на дашборде и `wrong_bot` в heartbeat убраны.
- Строки «можно писать первым» для полного незнакомца оставлены: без них после подготовительной бот не смог бы прислать онбординг в личку.
- Тесты: tests/test_other_bot_doors.py (11), всего 435. Четыре старых файла тестов входа переведены на подменённую общую базу — иначе они писали в настоящий sources/hadiths.db разработчика (случайную таблицу оттуда удалил).
- Снимки: logs/dash_variants/login_one_button.png, wrongbot_screen.png, wrongbot_dark.png (стенд без сервера: Playwright отдаёт файлы и подменяет API; настоящий telegram-web-app.js надо блокировать, он затирает window.Telegram).
