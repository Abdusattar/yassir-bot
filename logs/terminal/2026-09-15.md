# 2026-09-15 — сессия (тренажёр слов: второй порог зачёта)

## Решения

- **Зачёт «Слова» = 40 разных слов И 20 из них верно** (решение пользователя).
  «Верно» — хотя бы раз за день, позднейшая ошибка метку не снимает.
  Константа `DAILY_CORRECT_FOR_TASK_CREDIT = 20` рядом с `DAILY_WORDS_FOR_TASK_CREDIT`.
  Единый источник истины — `get_daily_words_status` в core/mufradat.py
  (count / correct / done); API, пилюля, дашборд пороги сами не сравнивают.
- **Чатовый Telegram-путь тренажёра убран целиком** (пользователь: «он больше
  не нужен»), вместе с `/muftop` (подтверждено отдельно: «убрать»). Удалены
  callback-ветки muf:/mufinc/mufdec/mufend/muftop/muflang* в bot.py, текстовый
  ввод страницы в handlers.py, карточки/меню языка/рейтинг-текст в
  core/mufradat_bot.py, core/mufradat_render.py + шрифт assets/fonts/, из
  requirements — uharfbuzz и freetype-py. mufradat_bot.py теперь — серверная
  часть сдач из приложения (зачёты, хифз, вердикты, дивизионы).
- **«Верно за сеанс» на карточке → «✅ верно сегодня 14/20»** (просьба
  пользователя). session_correct из API и состояния убран.
- **Верное слово не повторяется в тот же день.** Причина повторов (вопрос
  пользователя «зачем правильные за день выводить по несколько раз»): корзина
  закрепления (04.09) брала слова со стриком 1–2, куда сегодняшнее верное слово
  попадало сразу. Фикс: `exclude_keys` в generate_question/pick_question_word из
  `get_today_correct_keys`; действует и на «Мои слова»; снимается, если иначе
  пул пуст. Слова с ошибкой сегодня остаются в обороте.

## Показ (без лишнего шума, но понятно)

- Пилюля в шапке: «32/40 сегодня · ✅ 14/20», зелёная только по `daily_done`.
- Подсказка после ответа: «Ещё N слов и M верных…»; когда 40 есть, а верных
  нет — «40 слов есть ✅ Для зачёта «Слова» ещё M верных».
- Дверь «Тренажёры»/дашборд: «✅ Y/20 верных» дописывается только когда 40
  набрано, а зачёта нет.
- Поздравление: «40 слов проработано, 20+ из них верно».
- Локализация ky/uz — позже одним проходом (T() откатывается на русский).

## Миграция / выкладка

- `mufradat_daily_answered_words` получает колонку `correct` (ADD COLUMN, при
  первом обращении). Строки до выкладки — correct=0: кто уже начал день,
  верные наберёт из оставшихся слов. Лучше выкладывать не посреди дня.
