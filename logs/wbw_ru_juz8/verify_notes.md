# Независимая сверка джуза 8 (ворота 2), 14.11.2026
Прочитано 2566 слов. Найден один сдвиг.
- 6:135:10-12 مَن تَكُونُ لَهُ «кому / будет / принадлежать» - у لَهُ (предлог+местоимение) стоял чужой глагол «принадлежать». По принятому образцу (3:180 «то, / скупились они / на что»): «того, / будет / у кого».
На заметку: 7:80:1 وَلُوطًا «И Лута послали Мы,» - «послали Мы» подразумевается (в 7:65, 7:73, 7:85 у таких же начал глагола нет); единообразие на усмотрение.
